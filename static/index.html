Archive buckets

Store time ordered blobs in TAR archives. Each bucket has a fixed number of TAR files per hour. All buckets share the server's disk usage limit and oldest data is aged off when that limit is reached.

Access tokens

Enter the server's read and write tokens when configured. Tokens are used for this page's actions and are not saved by this page.

HTTP API

Upload raw bytes with POST /buckets/{bucket}/rawupload/{uuid}, or download with GET /buckets/{bucket}/get/{uuid}. Send the matching token as Authorization: Bearer <token>. Endpoints without a bucket selection use the default data bucket.
